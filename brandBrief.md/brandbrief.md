Please follow and build website with the same structure, design principles as https://orseundiris.com/

9. General Design & Functional Standards
Design System
ALL CAPS navigation & footer
Consistent typography across site
Consistent spacing and padding (clean editorial layout)

Animation Style
Minimal, refined, luxury feel
Subtle fades and hover transitions
No heavy or distracting animations

Performance
Fast load times prioritized (especially mobile)
Compressed images and optimized videos
Lazy loading across homepage, collections, product pages
Minimal unnecessary scripts

Accessibility
Keyboard navigation for all elements
ARIA labels for dropdowns, modals, forms
Alt text for all images
Strong color contrast

SEO
Structured data for products (price, availability, breadcrumbs)
Meta tags for all pages
Open Graph images for social sharing

Features
CMS flexibility (no developer needed for updates)
Wishlist / Save for Later
Filter breadcrumbs (removable filters)
Live chat integration
Back-in-stock notifications
